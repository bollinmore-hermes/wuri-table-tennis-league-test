# Wuri TT Test Pages

這是烏日桌球聯賽的**測試部署 Repository**，用於驗證尚未正式發布的功能。

- 測試網站：<https://bollinmore-hermes.github.io/wuri-table-tennis-league-test/>
- 正式原始碼：`bollinmore-hermes/wuri-table-tennis-league`

## 使用限制

- 測試站可能隨時更新、重設或暫時無法使用。
- 測試內容不代表正式賽程、戰績或排名。
- 除專案管理者另行授權外，請勿輸入真實個人資料或正式環境密碼。
- 測試站與正式站使用相互隔離的環境設定。

## 部署方式

此 Repository 只負責 Test GitHub Pages 部署，不維護應用程式原始碼副本。

Test workflow 可從正式原始碼 Repository 取用指定的分支、Git Tag 或 Commit，完成測試後產生測試網站。測試部署**不要求 Git Tag**；只有正式 Production 發布必須使用已有 Git Tag 的版本。

若發現安全問題，請透過正式原始碼 Repository 的 GitHub 私密安全回報機制通知維護者，不要在公開 Issue 揭露敏感細節。
